# mako

**여러 컴퓨터에서 코딩 에이전트를 실행하고 한 창에서 관리하세요.**

[English](README.md)

mako는 내 컴퓨터들을 비공개 메시 네트워크로 연결합니다. 빌드 서버에서 Codex를 실행하고, 노트북에서 변경 사항을 검토하거나, 휴대폰에서 Claude Code의 도구 실행 요청을 승인할 수 있습니다. 각 호스트의 데몬이 세션을 관리하므로 앱을 닫았다가 다시 연결해도 같은 터미널에서 이어서 작업할 수 있습니다.

## 빠른 시작

1. 각 컴퓨터에서 [go.mod](go.mod)에 지정된 Go 버전으로 저장소 루트에서 빌드합니다. 자세한 내용은 [빌드 가이드](DEVELOP.md#building)를 참고하세요.

   ```sh
   make build
   ./bin/mako-gui
   ```

   기본 설정에서는 데스크톱 앱이 실행 중인 데몬에 연결하거나, 데몬이 없으면 앱 내부에서 시작합니다. 화면이 없는 서버에서는 `./bin/makod`를 실행하세요.

2. **설정 → 노드**에서 연결할 컴퓨터 옆의 **접근 요청**을 선택합니다. 상대 컴퓨터에서 **설정 → 접근**을 열고 **허용**을 누릅니다. 같은 로컬 네트워크나 Tailscale 네트워크에 있는 노드는 자동으로 검색됩니다. 상대 노드의 주소를 직접 설정할 수도 있습니다. [네트워크 설정](docs/usage.md#configuration)
3. 탭 표시줄에서 에이전트를 선택해 세션을 시작합니다. 저장소 루트에서 CLI를 사용할 수도 있습니다.

   ```sh
   ./bin/mako nodes
   ./bin/mako agents
   ./bin/mako run claude
   ./bin/mako -node <node-id> run codex
   ./bin/mako ls
   ./bin/mako attach <session-id>
   ```

## 주요 기능

- **여러 호스트의 세션 관리.** 세션을 프로젝트나 호스트별로 모아 보고, 고정하거나 탭과 분할 창으로 열 수 있습니다. 앱을 닫거나 연결이 끊긴 뒤에도 기존 세션에 다시 연결할 수 있습니다.
- **터미널과 채팅.** 모든 세션에는 Ghostty 기반 터미널이 있습니다. 지원되는 에이전트는 채팅 화면에서 Markdown 응답, 도구 호출, 에이전트 활동을 확인할 수 있습니다. Claude Code와 Codex의 도구 실행 요청은 앱에서 승인할 수 있습니다. [데스크톱 앱 상세 가이드](docs/usage.md#the-desktop-app)
- **원격 프로젝트 작업.** 파일을 탐색하고 편집하거나, 변경 사항을 검토하고 Git 워크트리를 만들 수 있습니다. GitHub, Forgejo, Gitea의 풀 리퀘스트와 이슈를 열고, 포트 포워딩으로 원격 호스트의 `localhost` 링크에 접속할 수 있습니다. [데스크톱 앱 상세 가이드](docs/usage.md#the-desktop-app)
- **Android에서 접속.** 원격 세션을 시작하고 채팅이나 터미널을 열 수 있습니다. 지원되는 승인 요청은 알림에서 바로 처리할 수 있습니다. [Android 앱 및 빌드 방법](app/README.md)
- **Android 기기 빌려 쓰기.** 다른 노드가 공유한 Android 기기나 에뮬레이터를 `adb`로 사용하거나 에이전트 세션에 연결할 수 있습니다. [기기 공유 가이드](docs/devices.md)

## 지원 현황

| 대상 | 상태 |
|---|---|
| macOS, Linux | macOS는 일상적으로 사용 중입니다. Linux는 빌드와 테스트를 마쳤습니다. |
| Windows | 실험적 지원. ConPTY 세션과 테스트 코드는 빌드되며, 실제 실행 검증은 아직 진행되지 않았습니다. |
| Claude Code, Codex, 셸 | 안정 |
| Antigravity (`agy`) | 베타 |
| pi, oh-my-pi, 독립 실행형 OmO, OpenCode 및 OmO 플러그인 | 실험적 지원 |

채팅, 훅, 승인, MCP, 세션 재개 지원 범위는 에이전트마다 다릅니다. [에이전트별 지원 기능과 제약](docs/usage.md#agents)

## 접근 권한과 신뢰

노드를 승인하면 해당 노드가 승인한 호스트에서 프로그램을 실행하고 파일을 읽거나 쓸 수 있습니다. 접근 권한은 방향이 있으며, 신뢰 관계를 따라 다른 호스트에도 이어질 수 있습니다. 예를 들어 데스크톱이 노트북을 승인하고 빌드 서버가 데스크톱을 승인하면, 노트북은 데스크톱을 거쳐 빌드 서버에 접근할 수 있습니다. SSH 키로도 노드 간 신뢰를 설정할 수 있습니다. [접근 권한 및 네트워크 상세 가이드](docs/usage.md#security)
